## 2. Project Title

Simple Calculator with Menu

---

## 3. Project Description

This program is a simple calculator with a menu that allows users to perform basic mathematical operations, including addition, subtraction, multiplication, and division. The program also handles division by zero and allows users to perform calculations repeatedly until they choose the exit option.

---

## 4. Objectives

This project is designed to apply the following programming concepts:

- Variables
- Data types
- Operators
- Conditional statements
- Loops
- Algorithms
- JavaScript

---

## 5. Input

The program receives the following inputs from the user :
1. Menu choice (1-5):
- for Addition
- for Subtraction
- for Multiplication
- for Division
- to Exit
2. First number, used as the first operand for the selected operation.
3. Second number, used as the second operand for the selected operation.

---

## 6. Process

The program compares the player's guess with the target number.

If the guess is:

- Too high → the program provides a "too high" message
- Too low → the program provides a "too low" message
- Correct → the player wins

---

## 7. Output

The program displays:

- The result of each guess
- Hints or feedback
- The number of remaining attempts
- The final game status (win/loss)
